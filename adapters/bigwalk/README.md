# Big Walk

Send completed XRTranslate translations into Big Walk's native chat.

- [Install and use](../../docs/adapters/bigwalk/installation.md)
- [Bridge contract and development](../../docs/adapters/bigwalk/development.md)

The BepInEx IL2CPP bridge invokes the local player's normal chat command. Other
players receive ordinary game chat and do not need this bridge installed.
