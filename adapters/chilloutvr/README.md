# ChilloutVR adapter

Add a translation control and caption object to your avatar in its CCK project.
Choose a horizontal bubble, portrait bubble or transparent lettering, then move
and resize it in Unity's Scene view.

Import the downloadable Unity package and open **Tools → XRT-Avatar-Plugin →
ChilloutVR → Caption Objects**. Select your avatar, choose where to attach the
caption and press **＋**. Upload with the CCK, enable OSC in ChilloutVR and use
**XRT Translation** in Advanced Avatar Settings.
