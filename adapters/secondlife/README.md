# Second Life

Translation controls for an attachment or HUD you own. Show captions above it
or on another display prim in the same linkset.

[Set up Second Life](../../docs/adapters/secondlife/installation.md)

This setup uses the viewer's script editor, a local Node.js bridge and an HTTPS
relay. [Relay setup](../../docs/adapters/secondlife/relay-setup.md) and
[development](../../docs/adapters/secondlife/development.md) are documented separately.
